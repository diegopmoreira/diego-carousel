# Exemplos

Copy sintética de teste, sem atribuição editorial a Diego. IDs são opacos e
se repetem entre os arquivos. O caminho `$schema` de um projeto aponta para
`engine/schema/generated`. Estes exemplos ilustram os contratos; para um
projeto executável, usar `new` e `import-copy`, que também preservam a fonte.

Em tweaks, usar `slides.<id>.params`. Esta versão encapsula os IDs sob `slides`
para permitir `schema_version` e `$schema` sem ambiguidade.
