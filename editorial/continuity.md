# Continuidade

A pergunta deixada por um painel deve encontrar resposta no seguinte. Ler cada par adjacente e eliminar repetição de argumento. Uma mudança de registro precisa de ponte compreensível.

Variar a função do painel, não apenas o comprimento. Pausa serve para fixar uma descoberta; exemplo serve para testar uma distinção. O último painel não deixa pergunta pendente.
