# Arquiteturas

Escolher conforme a fonte: cena → diagnóstico → mecanismo → consequência → microação; crença → contradição → distinção → caso → aplicação; metáfora → desenvolvimento → limite → retorno à vida concreta.

Essas opções são ferramentas editoriais, não frameworks atribuídos a Diego. Usar 8–12 painéis, normalmente 10. Uma tese por carrossel. A última tela deve concluir o argumento antes de pedir uma ação.
